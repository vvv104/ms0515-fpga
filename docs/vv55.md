# КР580ВВ55А (Intel 8255A) - reference notes for the PPI model

These are the facts the pin-level model of КР580ВВ55А is built from. The
MS 0515 board (НС4) carries two of them: the system registers and the MS 7007
keyboard port (§10).

- **HV**: Хвощ С. Т., Варлинский Н. Н., Попов Е. А., *Микропроцессоры и
  микро-ЭВМ в системах автоматического управления. Справочник*, Л.:

## 1. Pins

DS Fig. 2 / p.3-100 and the pin-name table p.3-103; EC p.1 gives the same
numbering with Soviet names (ВА = port A, ВВ = port B, ВС = port C, D = data
channel). HV and EC agree on numbers 1-40; HV's PB list repeats pin 15 (a
typo in that source).

| Pin | Name (Intel / Soviet) | Dir | Function |
|---|---|---|---|
| 1-4 | PA3..PA0 / ВА3..ВА0 | I/O | Port A |
| 5 | -RD / RD | I | Read strobe, low active (DS p.3-101) |
| 6 | -CS / CS (ВК) | I | Chip select, low active (DS p.3-101) |
| 7 | GND | - | 0 V |
| 8 | A1 | I | Port select 1 |
| 9 | A0 | I | Port select 0 |
| 10-13 | PC7..PC4 / ВС7..ВС4 | I/O | Port C upper (group A) |
| 14-17 | PC0..PC3 / ВС0..ВС3 | I/O | Port C lower (group B); note the order: 14=PC0, 17=PC3 |
| 18-25 | PB0..PB7 / ВВ0..ВВ7 | I/O | Port B |
| 26 | VCC / Ucc | - | +5 V. DS: ±10 % (p.3-118). EC: 5 V ±5 % |
| 27-34 | D7..D0 | I/O, 3-state | Data bus; 27=D7, 34=D0 |
| 35 | RESET / SR ("установка в исходное состояние") | I | High active (DS p.3-102; HV) |
| 36 | -WR / WR | I | Write strobe, low active |
| 37-40 | PA7..PA4 / ВА7..ВА4 | I/O | Port A; 37=PA7, 40=PA4 |

Every port pin is bidirectional; its direction is set by the control word
(§3). There are no other pins: no clock (the chip is asynchronous to any
clock; DS has no clock parameter) [derived].

## 2. Bus interface

### 2.1 Basic operation (DS table "8255A Basic Operation", p.3-102)

| A1 | A0 | -RD | -WR | -CS | Operation |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 1 | 0 | Port A -> data bus |
| 0 | 1 | 0 | 1 | 0 | Port B -> data bus |
| 1 | 0 | 0 | 1 | 0 | Port C -> data bus |
| 0 | 0 | 1 | 0 | 0 | Data bus -> port A |
| 0 | 1 | 1 | 0 | 0 | Data bus -> port B |
| 1 | 0 | 1 | 0 | 0 | Data bus -> port C |
| 1 | 1 | 1 | 0 | 0 | Data bus -> control |
| X | X | X | X | 1 | Data bus 3-state |
| 1 | 1 | 0 | 1 | 0 | "Illegal condition" |
| X | X | 1 | 1 | 0 | Data bus 3-state |

- The control word register can only be written; no read of it is allowed
  (DS p.3-102). What D7..D0 do on the illegal read (A1A0=11, -RD low) is
  **not given**; KU calls it "undefined".
- -RD and -WR both low with -CS low: **not given** in DS.
- D7..D0 drive only while -CS and -RD are low; they float tDF after -RD
  rises (DS p.3-119, read timing p.3-123: "high impedance / valid / high
  impedance").

### 2.2 Which edge

- **Write**: data must be valid tDW before the trailing (rising) edge of -WR
  and held tWD after it; address and -CS held tWA after it (DS p.3-119). So
  the data are taken at the rising edge of -WR [derived]. The port output
  changes tWB after "WR = 1" (DS p.3-119, Mode 0 output waveform p.3-121
  [diagram]: OUTPUT moves after the -WR rising edge, not the falling one).
  OBF is set "by the rising edge of the WR input" (DS p.3-111). INTR (mode
  1/2 output) is reset by the **falling** edge of -WR (DS p.3-111), "INTR may
  rise/fall as early as WR falling" (DS p.3-121 note 3, on tWIT).
- **Read**: data valid tRD after -RD falls (DS p.3-119). In mode 0 the
  peripheral input need only be stable from tIR=0 before -RD falls to tHR=0
  after -RD rises (DS p.3-119, p.3-121 [diagram]); "inputs are not latched"
  (DS p.3-105), so the bus follows the pins while -RD is low [derived].
  Strobed side effects: INTR reset by the falling edge of -RD, IBF reset by
  the rising edge of -RD (DS p.3-109).
- Address and -CS: set-up 0 before and hold 0 (read) / 20 ns (write) after
  the strobe (DS p.3-119). Address changes while a strobe is low are **not
  given**.
- tRV = 850 ns minimum between the end of one read or write and the next
  (DS p.3-119).

### 2.3 What a read of a port returns

| Port, mode, direction | Returns | Source |
|---|---|---|
| A or B, mode 0, input | the pins, unlatched | DS p.3-105 |
| A or B, mode 1, input | the input latch (loaded by -STB) | DS p.3-109 ("both inputs and outputs are latched") |
| A, mode 2 | the input latch (loaded by -STB) | DS p.3-112, p.3-113 |
| A or B, configured as output | **not given** by DS, EC, HV or KU. DS describes port A as "one 8-bit data output latch/buffer and one 8-bit data input latch", port B as "input/output latch/buffer and one 8-bit data input buffer" (p.3-102), so for B the input buffer may sit on the pins. The emulator reads back the latch of the MS 7007 port A (`ms0515/src/core/src/board.c`, "port A reads its latch"). | open question 1 |
| C | see §7 | |

## 3. Control word (A1A0 = 11, write)

Bit 7 selects which of two words it is (DS Fig. 6 / p.3-104, Fig. 7 /
p.3-105; TD L.1101-1175, Рис.14 and Табл.9 agree).

### 3.1 Mode set, D7 = 1 (DS Fig. 6)

| Bit | Meaning |
|---|---|
| D7 | 1 = mode set flag |
| D6 D5 | Group A mode: 00 = mode 0, 01 = mode 1, 1X = mode 2 |
| D4 | Port A: 1 = input, 0 = output |
| D3 | Port C upper (PC7..PC4): 1 = input, 0 = output |
| D2 | Group B mode: 0 = mode 0, 1 = mode 1 |
| D1 | Port B: 1 = input, 0 = output |
| D0 | Port C lower (PC3..PC0): 1 = input, 0 = output |

- Group A = port A + PC7..PC4; group B = port B + PC3..PC0 (DS p.3-102).
- In mode 1/2 the port C bits taken by the handshake ignore D3/D0; the
  remaining bits follow them (DS Fig. 8-16, pp.3-110..3-114: e.g. mode 1
  port A input, D3 selects PC6,7; mode 1 port A output, D3 selects PC4,5;
  mode 2, D0 selects PC2..0). In mode 2 group A, D4 and D3 are drawn as don't
  care (Fig. 13 / p.3-113).
- The 16 mode 0 combinations: DS "Mode 0 Port Definition" p.3-106.

### 3.2 Port C bit set/reset, D7 = 0 (DS Fig. 7 / p.3-105)

| Bit | Meaning |
|---|---|
| D7 | 0 = bit set/reset flag |
| D6..D4 | don't care |
| D3..D1 | bit number 0..7 (D3 is the MSB) |
| D0 | 1 = set, 0 = reset |

- Any of the eight port C bits can be set or reset by one write (DS
  p.3-104). In mode 1/2 the INTE flip-flops are set/reset this way (§5.4).
- TD says the bit set/reset word "is permitted in mode 1 or 2" (L.1112-1113).
  DS does not restrict it; CM p.13 uses it on mode 0 outputs too. The model
  follows DS: it works in every mode.
- Effect on a port C bit programmed as input, or on a handshake input
  (STB/ACK) pin: CM p.13 says input lines are not affected, and a set/reset
  of the STB/ACK bit positions sets/resets the INTE flags instead. DS says
  only that INTE is controlled by bit set/reset of PC4/PC6/PC2 (§5.4).
  Whether a set/reset of an **input** bit changes the hidden output latch
  of that bit (seen if the bit is later made an output) is **not given**,
  moot anyway because a mode set clears the latches (§4).

## 4. What a mode-set write does

- "All of the output registers, including the status flip-flops, will be
  reset whenever the mode is changed" (DS p.3-104). KU and EC/HV-based
  dplm2008 page say the same in Russian.
- "All Mask flip-flops are automatically reset during mode selection and
  device Reset" (DS p.3-105): INTE A, INTE B, INTE 1, INTE 2 = 0.
- So after any mode-set word: port A, B and C output latches = 0; pins
  programmed as outputs drive 0 [derived]. IBF, OBF flip-flops and INTR are
  reset; in DS terms OBF F/F "set" means -OBF low (p.3-111), so reset ->
  -OBF pin high, IBF low, INTR low [derived; open question 3].
- Whether a write of the **same** mode word (the "mode is changed" wording)
  also clears is **not given**; the model clears on every mode-set write
  (open question 2). The MS 0515 ROM writes 202₈ at each start (TD L.1183-1186), so
  for the board it only matters that this clears.
- A port C bit set/reset word (D7=0) does not clear anything (DS p.3-104
  [derived from it being a separate word]).

## 5. RESET

- "A 'high' on this input clears the control register and all ports (A, B,
  C) are set to the input mode" (DS p.3-102); "all 24 lines will be in the
  high impedance state" (DS p.3-104). HV: same. After reset the chip can stay
  in input mode with no further initialization (DS p.3-104).
- Mask (INTE) flip-flops reset (DS p.3-105). Output latches: covered by
  "clears ... all ports" [derived: latches = 0].
- Pulse: at least 50 µs at or after power-on; afterwards 500 ns minimum
  (DS p.3-121 note 2).
- CM, not ours: 82C55A reset loads the control register with 9Bh and turns on
  bus hold (CM pp.2-4). DS says "cleared"; the effective state (all inputs,
  mode 0) is the same.
- KU claims RESET acts "only with /RD = 0 and /WR = 0"; no other source says
  so; ignored.

## 6. Mode 0 (DS p.3-105..3-109)

- Two 8-bit ports (A, B) and two 4-bit ports (PC upper, PC lower), each
  independently input or output: 16 combinations (DS p.3-105, p.3-106).
- "Outputs are latched. Inputs are not latched." No handshake (DS p.3-105).
- A write to a port programmed as output loads its latch; the pins follow
  tWB after -WR rises (§2.2).
- A write to a port programmed as input: **not given** by DS (open question 4).
- Port C written as a byte (A1A0=10) in mode 0: the bits of a half
  programmed as output take the data; DS p.3-115 says lower bits "can be
  accessed ... as a three-some by writing into Port C" in mode combinations,
  and upper bits "must be individually accessed using the bit set/reset
  function" (that sentence is about modes 1/2 with group A in mode 1/2).
  CM p.13: "only the Port C pins programmed as outputs in a Mode 0 group can
  be written" by a port C write.

## 7. Port C reads

DS p.3-115: in mode 0 port C reads the peripheral data; in modes 1 and 2 a
normal read of port C returns the status; there is no special instruction.

- Mode 0: input halves return pins [DS p.3-105]; output halves: **not
  given** (open question 1).
- Mode 1, status word (DS Fig. 17 / p.3-116):

| | D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0 |
|---|---|---|---|---|---|---|---|---|
| A in, B in | I/O | I/O | IBF_A | INTE_A | INTR_A | INTE_B | IBF_B | INTR_B |
| A out, B out | -OBF_A | INTE_A | I/O | I/O | INTR_A | INTE_B | -OBF_B | INTR_B |

  Group A and group B halves combine independently (A in + B out, etc.).
  In place of the -STB/-ACK pins (PC4, PC6, PC2) the INTE flags are read
  (DS Fig. 17; CM p.13 states it in words).
- Mode 2, status word (DS Fig. 18 / p.3-116): D7 -OBF_A, D6 INTE1,
  D5 IBF_A, D4 INTE2, D3 INTR_A, D2..D0 = group B (mode 0 I/O or mode 1
  status as above).
- "I/O" bits: input pins read as pins; DS p.3-115: "all input lines can be
  accessed during a normal Port C read". Output bits: **not given**.

## 8. Mode 1 (strobed), DS p.3-109..3-112

- Two groups; each has an 8-bit data port and a 4-bit control/data part of
  port C; "both inputs and outputs are latched" (DS p.3-109).
- Port C assignment (DS Mode Definition Summary p.3-115):

| Pin | A in | A out | B in | B out |
|---|---|---|---|---|
| PC0 | | | INTR_B | INTR_B |
| PC1 | | | IBF_B | -OBF_B |
| PC2 | | | -STB_B | -ACK_B |
| PC3 | INTR_A | INTR_A | | |
| PC4 | -STB_A | I/O | | |
| PC5 | IBF_A | I/O | | |
| PC6 | I/O | -ACK_A | | |
| PC7 | I/O | -OBF_A | | |

### 8.1 Input (DS p.3-109, Fig. 9 / p.3-110)

- -STB low loads the port pins into the input latch.
- IBF (output, high = full): set by -STB being low; reset by the rising
  edge of -RD.
- INTR: set when -STB is high ("a one"), IBF is 1 and INTE is 1; reset by
  the falling edge of -RD. On the waveform INTR rises tSIT after -STB rises
  [diagram].
- INTE A = PC4 bit set/reset, INTE B = PC2 (DS p.3-110).
- Data: set up tPS=0 before and held tPH=180 ns after the rising edge of
  -STB (DS p.3-119); the latch is "loaded" while -STB is low, closed at its
  rising edge [derived from tPS/tPH].

### 8.2 Output (DS p.3-111, Fig. 11)

- -OBF (output): goes low when the CPU has written the port; the F/F is set
  by the rising edge of -WR and reset by -ACK being low.
- -ACK (input): low = peripheral accepted the data.
- INTR: set when -ACK is high, -OBF is high ("one") and INTE is 1; reset by
  the falling edge of -WR. On the waveform INTR rises tAIT after -ACK rises
  [diagram].
- INTE A = PC6, INTE B = PC2.
- The port pins carry the latch at all times in mode 1 output (Fig. 11:
  OUTPUT changes tWB after -WR rises) [diagram]; contrast mode 2 (§9).
- CM p.9 adds: "OBF can go true before data is available"; data valid at
  the rising edge of -OBF. Not stated in DS.

## 9. Mode 2 (bidirectional, group A only), DS p.3-112..3-114, Fig. 15

- Port A is an 8-bit bidirectional bus, latched both ways; PC3..PC7 are
  control; PC2..PC0 belong to group B (mode 0 I/O or mode 1) (DS p.3-112,
  Fig. 13-16).
- PC3 INTR_A, PC4 -STB_A, PC5 IBF_A, PC6 -ACK_A, PC7 -OBF_A (DS p.3-115).
- Output side: -OBF low after the CPU writes port A. **-ACK low enables the
  port A output buffer; otherwise it is high-impedance** (DS p.3-112). Data
  appear tAD after -ACK falls and float tKD after it rises (DS p.3-119).
  INTE 1 (the OBF one) = PC6 set/reset.
- Input side: -STB low loads the input latch; IBF high = loaded. INTE 2 (the
  IBF one) = PC4 set/reset (DS p.3-113). CM p.10 says PC4 for INTE 1 as well:
  a CM error; DS is followed.
- INTR, as printed (DS Fig. 15 note, p.3-113): INTR = IBF · MASK · STB · RD
  + OBF · MASK · ACK · WR, with MASK, STB, RD, OBF, ACK, WR overbarred.
  Read with the mode 1 definitions, MASK is INTE (2 resp. 1) and the overbars
  mark the active-low signal names: INTR = (IBF and INTE2 and -STB high and
  -RD high) or (-OBF high and INTE1 and -ACK high and -WR high) [derived;
  open question 5]. The set/reset edges are as in mode 1.
- "Any sequence where WR occurs before ACK and STB occurs before RD is
  permissible" (DS Fig. 15 note).

## 10. On the MS 0515 board (TD)

Two КР580ВВ55, both on 16-bit bus addresses spaced by 2:

| Use | A | B | C | Control | Programmed as | Source |
|---|---|---|---|---|---|---|
| System registers | 177600 (write) | 177602 (read) | 177604 (write) | 177606 | 202₈ = 1000 0010: mode 0, A out, C upper out, B in, C lower out; written at power-on and every CPU restart | TD L.1076-1100, L.1183-1199 |
| MS 7007 keyboard ("параллельный интерфейс", also usable for ИРПР) | 177540 out (row scan) | 177542 in | 177544 in | 177546 | mode 0, A out, B and C in (TD); the word value is not printed - 1000 1011 = 213₈ [derived] | TD L.1696-1745 |

- System A bits: D7 ROM bank select, D6 cassette write, D5/D4 LEDs VD16/VD9,
  D3 floppy side, D2 motor (0 = on), D1..D0 drive number (TD L.1200-1247,
  Рис.15). B (read): D7 cassette read, D6..D5 reserved for ИРПР-М, D4..D3
  video frame rate, D2 drive ready (0 = ready), D1 ВГ93 DRQ, D0 ВГ93 INTR
  (TD L.1249-1293, Рис.16). C (write): D7 timer gate for sound, D6 sound
  enable, D5 tone, D4 LED VD17, D3 hi-res, D2..D0 border colour (TD
  L.1295-1325, Рис.17).
- Keyboard: the ROM writes zeros to all of port A; a key press pulls a line,
  an external comparator raises interrupt level 4, vector 60; the handler
  scans by writing a zero to each port A bit and looking for a zero on ports
  B and C (TD L.1717-1739). The PPI's INTR outputs are not used (mode 0)
  [derived].
- The TD register table labels 177540-177546 "Электроника МС 7004" (TD
  L.1865-1870) while §4.10.3 says МС 7007 (TD L.1699); the latter is meant.
- The mapping of bus address bits to A1/A0 (bus A2/A1 [derived from the
  spacing]) and the source of the PPIs' RESET are not in the TD text read.
- Only mode 0 is used on the board; modes 1/2 matter only if software sets
  them (the 177540 port's ИРПР use, TD L.1740-1741).

For the model:

- Port pins as inputs, and after RESET, are high-impedance: "all 24 lines
  will be in the high impedance state" (DS p.3-104). DS states no pull-up,
  pull-down or bus hold; leakage only (±10 µA). Bus hold (to logic 1, up to
  400 µA) is a CMOS 82C55A feature (CM pp.2-4) and does **not** apply [derived
  from DS silence + NMOS]. A floating input therefore reads whatever the
  board puts on it; the model should let the board's pull-ups decide and
  give `Z` from the PPI.
- Outputs: TTL push-pull; ports B and C also source the Darlington current
  (DS p.3-115). Port A in mode 2 is 3-state, gated by -ACK (§9).
- Data bus: 3-state except during a selected read (§2.1).

## 13. Conflicts between the documents

1. ICC: DS and EC 120 mA, HV < 60 mA. Port leakage: DS/EC 10 µA, HV 100 µA.
   VOL: DS/EC 0.45 V, HV 0.4 V. Supply: DS ±10 %, EC ±5 %. None affects a
   logic model.
2. INTE 1 in mode 2: DS PC6, CM PC4. DS followed.
3. Bit set/reset scope: TD "in mode 1 or 2" vs DS any mode. DS followed.
4. Reset value of the control register: DS "cleared", CM 9Bh. Both mean
   all ports input, mode 0.

## Open questions

The model must settle these by measurement of a real КР580ВВ55А, by
software on the board (ROM self-test, the emulator in lockstep), or by a
recorded choice.

1. **Read of an output port.** A, B, C bits programmed as outputs: the
   latch or the pins? DS, EC, HV, KU are silent. Matters only if a pin is
   overdriven (it is not on НС4 [derived]); the emulator returns the latch.
2. **Mode-set clearing.** Does a mode-set word equal to the current one
